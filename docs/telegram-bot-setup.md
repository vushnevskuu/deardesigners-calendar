# Подключение Telegram-бота к календарю

Календарь умеет автоматически создавать события из постов в Telegram-канале или
чате клуба. Бот ничего не публикует обратно — он только слушает.

Документ состоит из двух частей:

1. **Чек-лист для хозяев клуба** (нужно сделать вручную в Telegram).
2. **Чек-лист для разработчика** (нужно сделать в Vercel — один раз).

---

## 1. Чек-лист для хозяев клуба (5 минут)

> Существующий бот в канале **не подойдёт**. Telegram не даёт другим людям
> токен чужого бота. Мы создаём отдельного бота специально для календаря.

### Шаг 1. Создать бота
1. Открыть в Telegram чат с `@BotFather`.
2. Отправить `/newbot`.
3. Имя бота: например **«Дорогие дизайнеры — Календарь»**.
4. Username: например **`DearDesignersCalendarBot`** (должен заканчиваться на `bot`).
5. В ответ придёт сообщение с токеном вида `123456789:AAH...`. **Это секрет.**
   Передать его разработчику любым приватным каналом.

### Шаг 2. Выключить privacy mode (нужно если бот будет в чате)
1. У `@BotFather` отправить `/setprivacy`.
2. Выбрать только что созданного бота.
3. Ответить `Disable`.
   (Иначе бот будет видеть только сообщения с упоминанием `@bot`.)

### Шаг 3. Добавить бота в КАНАЛ клуба админом
1. В Telegram → канал клуба → **Управление каналом** → **Администраторы** →
   **Добавить администратора**.
2. Найти бота по username (`DearDesignersCalendarBot`) и добавить.
3. Достаточно прав «Публикация сообщений» (на самом деле бот ничего не
   публикует, но Telegram не доставит ему `channel_post` без админских прав).

### Шаг 4. (опционально) Добавить бота в ЧАТ клуба
Если хочется, чтобы события создавались и из обсуждений в чате — добавить бота
в чат и сделать админом тем же способом.

### Шаг 5. Что прислать разработчику
- Токен бота: `123456789:AAH...`
- Юзернейм или ссылка на канал клуба (например `@deardesigners`).
- Юзернейм или ссылка на чат клуба, если бот добавлен и в чат.

---

## 2. Чек-лист для разработчика (Vercel + база)

Перед началом нужно:
- доступ к проекту `deardesigners-calendar` в Vercel;
- три секрета: `TELEGRAM_BOT_TOKEN` (от хозяев), `WEBHOOK_SECRET` (любая
  длинная случайная строка), `ADMIN_SECRET` (любая длинная случайная строка).

### Шаг 1. Подключить Postgres и Blob
В Vercel Dashboard → проект `deardesigners-calendar`:
1. **Storage → Create Database → Postgres** (через Marketplace, провайдер на
   выбор: Neon рекомендуется, бесплатный тариф). Привязать к проекту → Vercel
   автоматически создаст env-переменные `POSTGRES_URL`, `POSTGRES_PRISMA_URL`
   и др.
2. **Storage → Blob → Create Blob Store** → привязать к проекту. Vercel
   создаст `BLOB_READ_WRITE_TOKEN`.

### Шаг 2. Добавить остальные env-переменные
Settings → Environment Variables (для Production):

| Имя | Значение | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | от хозяев клуба | токен бота |
| `WEBHOOK_SECRET` | сгенерировать через `openssl rand -hex 24` | защита webhook |
| `ADMIN_SECRET` | сгенерировать через `openssl rand -hex 24` | защита /api/admin/* |

### Шаг 3. Передеплоить
Любой коммит или Redeploy через Vercel UI — функции подхватят env.

### Шаг 4. Инициализировать схему БД
Один раз. Заменить `<PROD_URL>` на боевой URL (например
`https://deardesigners-calendar.vercel.app`):

```bash
curl -X POST https://<PROD_URL>/api/admin/setup \
  -H "X-Admin-Secret: $ADMIN_SECRET"
# Ожидаемый ответ: {"ok":true}
```

### Шаг 5. Зарегистрировать webhook у Telegram
```bash
curl -X POST https://<PROD_URL>/api/admin/set-webhook \
  -H "X-Admin-Secret: $ADMIN_SECRET" \
  -H "Content-Type: application/json" \
  -d '{}'
# Ожидаемый ответ: {"ok":true,"url":"...","telegram":{"ok":true,"result":true,...}}
```

Проверить статус:
```bash
curl https://<PROD_URL>/api/admin/webhook-info \
  -H "X-Admin-Secret: $ADMIN_SECRET"
# В поле "result.url" должен быть https://<PROD_URL>/api/tg-webhook
# pending_update_count = 0 → норма
```

### Шаг 6. Проверить
1. Опубликовать тестовый пост в канале клуба:
   ```
   Тестовое событие 31 мая в 19:00, всем привет.
   ```
2. Через 5–10 секунд:
   ```bash
   curl 'https://<PROD_URL>/api/events?month=2026-05'
   ```
   В ответе должен появиться объект с `title`, `date: "2026-05-31"`, `time: "19:00"`.
3. Открыть `https://<PROD_URL>/homepage?month=2026-05` — событие должно
   появиться в сетке.
4. Опубликовать пост с фото — карточка должна показать обложку.

## Что бот делает с постом

- Текст поста (или caption у фото) → `description` события.
- Первая строка / первое предложение → `title` события (≤ 90 символов).
- Дата из текста (`«31 мая»`, `«25.06»`, `«завтра в 19:00»`) → `date + time`.
- Если в тексте даты нет → берётся **дата публикации поста**.
- Тип события (`talk` / `worman` / `offline` / …) определяется по ключевым
  словам в тексте. Если ничего не совпало — `other`.
- Самое крупное фото из поста → скачивается в Vercel Blob, ссылка кладётся в
  `cover_url`.
- Постоянная ссылка `https://t.me/<channel>/<msg_id>` → `telegram_post_url`,
  отображается в карточке события.

## Что бот **не** делает

- Не публикует ничего в Telegram.
- Не читает историю канала/чата (Telegram Bot API физически не позволяет).
   Создаются только события из постов после подключения webhook.
- Не редактирует события вручную — это делает команда клуба в admin-режиме.
- Не отправляет файлы и документы — пока поддерживаются только фото.

## Если что-то пошло не так

- `/api/events` вернул 503 → не подключён Postgres (или env-переменные не
  попали в Production-окружение).
- `/api/admin/webhook-info` показывает `last_error_message` → Telegram не
  смог достучаться до webhook'а. Чаще всего: неверный URL или
  `WEBHOOK_SECRET` не совпадает.
- В логах `/api/tg-webhook` пишет `ignored: empty_text` → бот получил пост
  без текста и без caption (например, репост). Это нормально, событие
  не создаётся.
- Картинка не подгрузилась → проверить что Blob подключён (env
  `BLOB_READ_WRITE_TOKEN`).
