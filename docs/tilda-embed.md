# Tilda · Embed Widget

Календарь сообщества «Дорогие дизайнеры» — это **самостоятельное web-приложение**,
которое можно встроить **в любую страницу сайта на Tilda** (или любую другую CMS).

Не обязательно делать его первым экраном. Можно поставить календарь:

- на главную как hero-блок (`/homepage`),
- на отдельную страницу «Календарь» (`/embed`),
- в середину лендинга или статьи (`/embed?compact=true`),
- в архив или дайджест (`/digest?month=YYYY-MM`),
- в промо-страницу набора в клуб.

## Четыре режима

| Режим | Путь | Что показывает |
| --- | --- | --- |
| **Embed** | `/embed` | Только сетка месяца с навигацией. Без hero, CTA и подвалов. Идеален для вставки внутрь страницы. |
| **Homepage** | `/homepage` | Hero, CTA, навигация по месяцам, архив. Большой промо-блок для главной. |
| **Digest** | `/digest` | Прошедший месяц как отчёт «что было в клубе». Без hero. С архивом-стрипом. |
| **Admin** | `/?mode=admin` (или `/`) | Закрытая админка: редактор, autofill, экспорт. Не для внешнего сайта. |

> На прод-домене предполагаются пути `/embed`, `/homepage`, `/digest`, `/admin`.
> На статическом хостинге без CDN-rewrite используйте query-форму:
> `/?mode=embed`, `/?mode=homepage`, `/?mode=digest`.

## Готовые iframe-снипеты для Tilda

В Tilda добавьте блок **T123** (HTML) или **T126** (Embed HTML Code) и вставьте
один из шаблонов ниже.

### 1. Компактный календарь внутри страницы

```html
<iframe
  src="https://calendar.deardesigners.club/embed?month=2026-06&compact=true&showPast=true"
  style="width:100%;min-height:760px;border:0;border-radius:32px;overflow:hidden;display:block;"
  loading="lazy"
  title="Календарь Дорогих дизайнеров"
></iframe>
```

Подходит для: страницы «Календарь», статьи, лендинга набора.

### 2. Большой промо-блок на главной

```html
<iframe
  src="https://calendar.deardesigners.club/homepage?month=2026-06"
  style="width:100%;min-height:1100px;border:0;border-radius:0;overflow:hidden;display:block;"
  loading="lazy"
  title="Календарь Дорогих дизайнеров"
></iframe>
```

Подходит для: первого экрана сайта, промо-страницы клуба.

### 3. Дайджест прошедшего месяца

```html
<iframe
  src="https://calendar.deardesigners.club/digest?month=2026-05&showTelegramLinks=true"
  style="width:100%;min-height:980px;border:0;border-radius:32px;overflow:hidden;display:block;"
  loading="lazy"
  title="Дайджест клуба за месяц"
></iframe>
```

Подходит для: monthly recap, архивных страниц, рассылки.

## Все поддерживаемые query-параметры

Параметры опциональные. Если не указан — берётся дефолт компонента или
admin-настройка проекта.

| Параметр | Значения | Где работает | Что делает |
| --- | --- | --- | --- |
| `mode` | `embed`, `homepage`, `digest`, `admin` | везде | Режим приложения. Альтернатива пути `/embed`/`/homepage`/`/digest`. |
| `month` | `YYYY-MM` (например `2026-06`) | везде | Открыть конкретный месяц. |
| `view` | `calendar`, `digest`, `compact` | embed/homepage | Подсказка о фокусе. `view=digest` приравнивается к `presentation=monthly-digest`. |
| `presentation` | `upcoming`, `monthly-digest`, `archive` | homepage | Презентация календаря: программа / дайджест / архив. |
| `compact` | `true`, `false` | embed/homepage/digest | Компактные карточки. Для embed дефолт `true`, для остальных `false`. |
| `showPast` | `true`, `false` | embed/homepage/digest | Показывать ли блок «Уже прошло в этом месяце». |
| `showMaterials` | `true`, `false` | везде | Показывать ли материалы и фишки внутри карточек. |
| `showTelegramLinks` | `true`, `false` | везде | Показывать ли кнопку «↗ Telegram» в карточках. |
| `theme` | `light`, `clean`, `paper` | везде | Фон контейнера: тёплый paper (дефолт), холоднее `light`, белый `clean`. |
| `height` | `auto`, `fixed` | везде | `auto` — естественная высота (рекомендуется для Tilda). `fixed` — растянуть на 100vh. |

Булевы значения принимают `true`/`false`, `1`/`0`, `yes`/`no`, `on`/`off`.

## Поведение публичных режимов

- редактор не показывается — никаких plus-кнопок, drawer-ов, drag&drop,
- видны только события с `publishStatus = "published"`,
- события с `visibility = "private"` полностью скрыты,
- события с `visibility = "members_hint"` показывают дату, тип и кнопку
  Telegram с подсказкой «Доступно участникам клуба» — без описания и материалов,
- виджет адаптивен по ширине контейнера, без горизонтального скролла,
- картинки рендерятся через SmartImage (cover/contain + blur/solid background).

## Как поменять месяц без переразворачивания

Месяц задаётся в `?month=YYYY-MM`. Можно держать в Tilda несколько HTML-блоков
с разными `month=` под разные сценарии (например, страница «Архив 2026»):

```html
<!-- Январь -->
<iframe src=".../digest?month=2026-01" ...></iframe>
<!-- Февраль -->
<iframe src=".../digest?month=2026-02" ...></iframe>
```

В embed/homepage пользователь сам перелистывает месяцы стрелками. Если нужно
жёстко зафиксировать конкретный месяц — отключите внутренние стрелки логически:
для этого передайте `view=digest` или используйте `/digest`.

## Telegram-ссылки и приватность

- Telegram-токены **не используются на фронтенде**. Парсер сообщений работает
  на уже сохранённых данных, импортированных через бэкенд или загруженных
  вручную. Никаких секретов в Tilda.
- Реальный доступ к Telegram-посту защищён правами на чат: если пользователь
  не состоит в закрытом сообществе, Telegram сам ограничит доступ.
- Через `showTelegramLinks=false` можно скрыть кнопки целиком — например,
  для публичных страниц без приглашения в клуб.
- Любой serverside-слой (импорт сообщений, авторизация, синхронизация с
  Telegram Bot API) живёт **отдельно от этого фронтенда** и не должен
  засовываться в Tilda HTML.

## Высота iframe и адаптив

- Не используйте `height: 100vh` — контент часто длиннее одного экрана.
- Указывайте `min-height` (700–900 px для embed, 1000–1300 px для homepage,
  900–1100 px для digest) и `width:100%`.
- Для тёмных лендингов передавайте `theme=clean` (белый фон календаря,
  чтобы он не «глотал» внешнюю секцию Tilda).
- Если хочется сделать «честную» полноэкранную секцию — `height=fixed`
  растягивает контент на 100vh, но всё равно следите за реальной длиной.

## Альтернатива: script-widget (на будущее)

iframe — самый простой и безопасный путь для MVP. Если в будущем понадобится
script-widget (внутри DOM Tilda без iframe), нам потребуется:

- собирать продакшн-бандл календаря в виде самовызываемого скрипта,
- предоставлять mount-функцию `window.DDCalendar.mount(el, options)`,
- решать вопросы CSS-изоляции (Shadow DOM или namespaced classes),
- уметь синхронизировать высоту контейнера с контентом (postMessage).

Это вне scope текущего MVP — все три режима выше работают через iframe.
